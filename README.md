# 👕 Zoubir-Trends

Zoubir-Trends is a modern e-commerce web application for clothing or fashion trends (as suggested by the name). It provides a smooth online shopping experience with a clean and responsive user interface. The project is built with a clear separation between frontend and backend.

🌐 **Live Demo**: [zoubir-trends.vercel.app](https://zoubir-trends.vercel.app)

---

## ✨ Key Features

- 🛒 **Product Browsing**: View products with details and images.
- 🛍️ **Shopping Cart**: Add, update, or remove items easily.
- 📱 **Responsive Design**: Works perfectly on all devices (mobile, tablet, desktop).
- ⚡ **Fast Performance**: Optimized for quick loading and interactions.
- 🔧 **Modular Architecture**: Separated frontend and backend for easy maintenance.
